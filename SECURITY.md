# Security

Only the latest alpha is maintained, on a best-effort basis without response
or fix deadlines. This experimental release has no security audit guarantee.

Please report suspected vulnerabilities privately through GitHub's
**Report a vulnerability** button on this repository's Security tab. Do not
include sensitive paths, filenames, credentials or exploit details in a public
issue. If private reporting is unavailable, open an issue requesting a private
contact without disclosing the vulnerability itself.

The scanner reads metadata for an explicitly selected folder and reports
permission failures. Never run the application as root to bypass permissions.
